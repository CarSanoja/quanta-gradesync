# Security

## Reporting

Found something? Open a GitHub issue, or write to contact@somosquanta.com. This
is a hackathon submission, not a supported product; there is no SLA, but a real
report will get a real answer.

## What the deployed demo exposes

One gate sits in front of every router (`src/autocurricula/api/gate.py`).

Public without a code — the shells a person needs before they can type one:

- `/teacher` and `/console`
- `/teacher/assets/*`, `/console/assets/*`, `/console/diagrams/*`
- `/readyz`

Everything else answers `401` without a code and `403` with a wrong one,
including `/openapi.json`. That covers every route carrying data: jobs, the
review queue, the SIS ledger, the fleet registry, the live feed, ingest.

The code is compared in constant time. A deployment with no code configured
admits nobody.

## How the code travels

The two pages keep it in `localStorage`, for that browser only, and send it as a
bearer token. Pub/Sub push sends the same value as a `?token=` query parameter,
because its OIDC token already occupies the `Authorization` header — that
collision is [documented upstream](docs/submission/blog-medium.md) and cost us
an afternoon of silent 403s.

## Known limitations

- **One secret does two jobs.** The access code is the same value that
  authenticates Pub/Sub push, so anyone holding it can also post to `/ingest`.
  That is deliberate for judging — the judge guide's "trigger a real run" step
  needs it — and should be split into two secrets afterwards.
- **No per-user identity.** The code is shared, not personal. There is no audit
  trail of *which human* approved a grade, only that a human did.
- **Agent identity is logical.** Agents carry principals and capability scopes
  enforced in-process; they are not separate IAM service accounts. The
  enforcement point is the harness, not Google IAM.

## What is not in this repository

No credentials, no tokens, no student data. Every exam page under `docs/` and in
the test fixtures is synthetic and generated by
`scripts/generate_sample_batch.py`. The demo's access code lives in Secret
Manager and is handed to judges through the submission form, never committed.
