How to name your files

GradeSync reads the student from the file name: ana-torres.pdf shows up in the gradebook as Ana Torres.

  • ✓ One file per student: ana-torres.pdf, luis-perez.jpg
  • ✓ Several pages? Scan them into one PDF, pages in order, and upload that single file.
  • ✗ ana-torres-p1.jpg + ana-torres-p2.jpg — two files make two students, “Ana Torres P1” and “Ana Torres P2”.

Upload a file name that already has a scan and we ask first: replace the saved scan (the exam is re-graded and the old scan is kept) or save it as a different student. Nothing is renamed on its own.
